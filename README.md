# Dragology

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:5173

## The site

[declarative-dragging.github.io](https://declarative-dragging.github.io) is laid out by the Pages workflow (`.github/workflows/main.yml`):

- `/`: the project page, `home/`, with its live figures built from `page/` into `home/js/` (see [page/README.md](page/README.md))
- `/uist26/`: the demo build (`npm run build`), the paper's interactive supplement; `/supplement/` redirects there
